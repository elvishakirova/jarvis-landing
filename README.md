# Джарвис — «Создаём Джарвиса»

Редизайн лендинга интенсива «Создаём Джарвиса» (Константин Урванцев, Елизавета Роменская), 15–16 сентября 2026, Москва.

Каждая страница — самостоятельный, самодостаточный HTML-файл (вся CSS и JS инлайн, шрифты — Google Fonts), без сборки и зависимостей. Откройте любой файл прямо в браузере.

## Страницы

- `index.html` — главная страница (открывается по умолчанию, в том числе на GitHub Pages)
- `program.html` — программа по часам
- `oferta.html` — публичная оферта
- `privacy.html` — политика обработки персональных данных

## Ассеты

- `img/` — фотографии ведущих (оригиналы и уменьшенные версии); в сами HTML-файлы фото встроены как base64 data URI, так что папка нужна только как резервная копия исходников
- `content.md` — исходный текстовый контент сайта
