# Дизайн-система «Создаём Джарвиса»

Стайлгайд по редизайну лендинга интенсива. Описывает все визуальные правила, использованные в `index.html`, `program.html`, `oferta.html`, `privacy.html` — цвета, шрифты, отступы, компоненты, анимации. Все страницы — самостоятельные HTML-файлы с инлайн CSS/JS, без сборки; переменные ниже объявлены в блоке `:root` каждого файла.

## 1. Философия

Тёмный «интерфейсный» стиль в духе консоли/IDE: один фон на весь сайт (без переключения тёмная/светлая тема), акцентный янтарный цвет, моноширинный шрифт для «технических» деталей (бренд, цены, метки), острые углы почти везде — единственное исключение декоративно скошено «под кнопку». Много самостоятельно нарисованных на CSS элементов вместо иконочных библиотек: точки-разделители, «дрейфующие» орбиты, псевдо-курсор, обучающий /`~/jarvis` префикс.

## 3. Шрифты

Два шрифта на весь сайт, оба объявлены как токены:

```css
--font-display: system-ui, -apple-system, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
--font-mono:    "Cascadia Code", ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace;
```

`Cascadia Code` подключается из Google Fonts (`wght@500;600`) — это единственный внешний шрифт, `--font-display` — системный стек без загрузки.

Роли:

- **`--font-display`** (system-ui) — все заголовки `h1/h2/h3`, тело текста (`body`), кнопки. Это шрифт «для чтения».
- **`--font-mono`** (Cascadia Code) — «акцентный/технический» шрифт: логотип `~/jarvis`, эйброу-лейблы (`.eyebrow`), цены и цифры (`.price-amount`, `.price-old`), URL-строка и статус в hero-мокапе браузера, номера шагов, тайминги программы (`.agenda-time`), футер-реквизиты, фавикон (буква J).

## 4. Сетка, контейнер, отступы между блоками

```css
--container: 1200px;   /* max-width контента */
--pad-x: 20px;          /* боковой паддинг .container */
```

- `.container` — `max-width:1200px; margin-inline:auto; padding-inline:20px`.
- Вертикальный ритм между блоками задаётся ОДНИМ значением на весь сайт: `padding-block: clamp(56px, 9vw, 112px)` на каждом `<section>`. Так как у соседних секций складываются paddings, между блоками получается до ~224px на широких экранах.
- Внутрисекционный разделитель (`.section-seam`, между инструкторами и отзывами) использует тот же `clamp(56px,9vw,112px)`, но как `margin: … 0` — то есть отступ идентичен межсекционному, хотя элемент не является отдельным `<section>`.
- Заголовок блока (`.section-head`) — `margin-bottom: clamp(32px, 5vw, 56px)`.
- Сетки карточек (`.grid`) — `gap: 20px` всегда, независимо от количества колонок.
- Отдельный частный случай: там, где перед секцией стоит оранжевая CTA-плашка (`.cta-band`) вне `<section>`, у предыдущей секции паддинг снизу принудительно уменьшен до `20px` (`section:has(+ .container > .cta-band)`), а у самого контейнера с плашкой добавлен `margin-bottom: clamp(56px,9vw,112px)` — чтобы плашка «прилипала» к секции над собой, но перед следующим блоком всё равно был стандартный воздух.

## 6. Форма — углы и обводка

Сайт принципиально острый: `border-radius` нигде не используется для прямоугольных блоков (легаси-токены `--radius-card/--radius-btn/--radius-chip` объявлены в `:root`, но фактически не применяются ни к одному селектору). Вместо скругления везде, где нужен акцент «интерфейсности», используется `clip-path: polygon(...)` — скошенный (chamfered) уголок только по двум противоположным углам (верхний левый + нижний правый), это визуальная подпись бренда:

```css
/* пример на кнопке */
clip-path: polygon(8px 0, 100% 0, 100% calc(100% - 8px), calc(100% - 8px) 100%, 0 100%, 0 8px);
```

Размер фаски масштабируется под размер элемента:

| Элемент | Фаска |
|---|---|
| `.btn` | 8px |
| `.btn-sm` | 6px |
| `.burger` | 7px |
| `.scroll-top-btn` | 9px |
| `.cta-band` | 16px (12px на ≤480px) |
| `.final-cta` | 24px |

Все остальные блоки (карточки, инпуты, теги) — прямые 90°-углы, обводка `1px solid var(--border-dark)` (или `var(--amber)` для акцентных/активных состояний).

## 7. Компоненты

### Кнопки (`.btn`)
- Базовый класс: flex, gap 10px, шрифт `--font-display` 500 16px, паддинг 14px 24px, обводка 1.5px, скошенный угол 8px.
- Варианты заливки: `.btn-primary` (amber/amber-ink), `.btn-outline-dark` (прозрачный + `--border-dark`, hover → amber), `.btn-outline-light` (для светлых поверхностей, сейчас не используется), `.btn-on-amber` (тёмная кнопка поверх оранжевой плашки).
- `.btn-sm` — уменьшенная версия (10px 18px, 14px, фаска 6px).
- Hover: подъём `translateY(-2px)` + смена цвета/тени; active — `translateY(1px)`.
- Стрелка `→` внутри кнопки (`.btn-arrow`) сдвигается на 3px вправо при hover.

### Шапка (`.site-header`)
- `position: sticky`, полупрозрачный фон `rgba(10,6,0,.86)` + `backdrop-filter: blur(10px)`, высота 50px, нижняя обводка `--border-dark`.
- Сетка `1fr auto 1fr`: бренд слева, нав по центру, CTA справа.
- Бренд `~/jarvis` — моно, 600, буква после `~/` подсвечена amber.
- Под 900px нав прячется, включается бургер (40×40px, фаска 7px); мобильная панель — полноэкранный оверлей с крупными (19px) пунктами меню.

### Hero
- Мокап окна браузера: `.browser-chrome` (полоска с точками-«трафлайтами» + строкой URL + статусом ONLINE, мигающая точка) поверх `.browser-body` (реальный контент).
- На ≤480px `.browser-chrome` переносится в две строки (точки+статус сверху, поле URL — на всю ширину снизу) — это единственное место с ручным `flex-wrap` вместо простого сжатия.
- Декор: две пунктирные орбиты (`.orbit-ring`, `.orbit-ring-2`) с разной скоростью вращения, «сеть» дрейфующих заметок на canvas/SVG (скрыта ≤1000px), «мысли»-чипы по углам (скрыты ≤860px).

### Карточки
- Общий `.card`: обводка `--border-dark`, фон `--ink-2`, паддинг 30/20px, при hover — подъём -4px, обводка становится amber, фон светлеет до `--ink-3`.
- Значковый блок `.icon-badge` — 44×44px, фон `rgba(amber,.14)`, при hover карточки — поворот -8° и увеличение 1.08×.
- Специализации: `.card-neg`/`.card-pos` (сравнение офлайн/онлайн — приглушённая и акцентная версии), `.program-card` (программа по дням), `.person-card` (инструкторы, аватар 72px с градиентом amber→#c97f12), `.t-card` (отзывы в бесконечной ленте `.marquee-track`, 160s анимация, пауза на hover), `.check-row` (чек-лист).
- Цена: `.price-feature` — акцентная карточка (обводка amber, фон как у обычных карточек), `.price-row` — обычные строки тарифов, `.price-row.active` — подсвечена полупрозрачным amber.

### Разделители между блоками
- `.seam` — тонкая (1px) градиентная амбер-линия сверху секции, «дорисовывается» через `scaleX(0→1)` при появлении в вьюпорте (класс `.in-view`, ставится через IntersectionObserver).
- `.section-seam` — та же линия, но как самостоятельный блок внутри секции (между инструкторами и отзывами), с отступом `clamp(56px,9vw,112px)` сверху/снизу — визуально неотличим от обычного стыка секций.

### CTA-плашки
- `.cta-band` — оранжевая плашка на всю ширину контейнера между блоками текста, скошенный угол 16px (12px на мобиле), внутри дрейфующая точка-акцент (`.cta-band::after`, 5s анимация).
- `.final-cta` — увеличенная финальная версия перед футером, скошенный угол 24px, паддинг не сжимается на мобиле.

### FAQ-аккордеон
- Двухколоночная сетка вопросов (`.faq-grid`, 56px между колонками, 1 колонка ≤800px).
- Индикатор — самодельный крест `.plus` из двух `::before/::after`-полосок 21×3px (нечётная длина/толщина для идеально центрированного пересечения), **прямые концы без скругления** (важно: `border-radius` здесь намеренно не используется, в отличие от чипов и точек в других местах сайта). При открытии вертикальная полоска поворачивается на 90° и гаснет, оставляя «минус».

### Футер и мелкие утилиты
- `.footer-grid` — 1.3fr/1fr, реквизиты моно 12.5px.
- `.scroll-top-btn` — плавающая кнопка 44×44, фаска 9px, появляется по скроллу.
- `.cookie-banner` — плавающая карточка снизу-слева (420px, фаска не используется — обычная прямоугольная карточка), на ≤480px растягивается на всю ширину с боковыми отступами 20px.

### Страница программы (`program.html`)
- Таймлайн дня: `.agenda-item` — сетка `96px 1fr` (время слева моно-шрифтом amber, контент справа), разделитель `--border-dark` снизу каждого пункта.
- `.feature-tags` — теги-инструменты, моно 13px, обводка `--border-dark`, паддинг `9px 14px`.

### Юридические страницы (`oferta.html`, `privacy.html`)
- Единый паттерн `.doc-section`/`.doc-intro`: верхняя граница-разделитель, `h2` заголовок раздела, текст `16px/1.7` шириной до `78ch`, приглушённый цвет `--on-dark-soft`.
- Списки без маркеров, вместо буллета — псевдоэлемент `—` цвета amber (`.doc-section ul li::before{ content:"—"; color:var(--amber); }`).
- `.doc-req` — блок реквизитов, моно 13px/1.9, приглушённый цвет.

## 8. Анимация и интерактивность

- Общий easing на весь сайт: `--ease: cubic-bezier(.22,.8,.28,1)`.
- Появление при скролле: класс `.reveal` (`opacity:0`+`translateY(18px)` → `.in-view` снимает трансформацию за 0.7s); `.reveal-stagger > *` добавляет ступенчатую задержку `calc(var(--i) * 70ms)` для последовательного появления карточек в сетке.
- `prefers-reduced-motion: reduce` — глобально сокращает все анимации/transition до `.001ms` и отключает плавный скролл.
- Точечные декоративные keyframes: `spin` (орбиты, 220s/320s), `node-float` (сеть заметок, 20s), `chip-float` (мысли-чипы, 15–19s), `blink` (курсор/статус ONLINE), `drift` (точка в CTA-плашке, 5s), `travel` (бегущая точка по линии шагов, 4.5s), `marquee` (лента отзывов, 160s, линейно).

## 10. Фавикон

Квадратная тёмная иконка (`--ink` фон) с крупной буквой **J** акцентным моноширинным шрифтом (Cascadia Code, вес 600), цвет `--amber`. Сгенерирована в трёх размерах (16, 32, 180px), встроена в `<head>` каждой страницы как inline `data:image/png;base64,…` — отдельных файлов на сервере не требуется. Оригиналы PNG лежат в `img/favicon-*.png` как резервная копия.
